# Architecture

System architecture for jamf-reports-community is documented in two places:

- **[`docs/architecture/`](docs/architecture/)** — architecture decision records
  (ADRs), the repository threat model, and the jamf-cli-first design narrative.
- **[`CLAUDE.md`](CLAUDE.md)** — the working architecture reference: the component map,
  class responsibilities, jamf-cli JSON shapes, and invariants for both the Python CLI
  and the Swift app.

Operator-facing documentation — installation, dashboards, scheduling, configuration, the
Python CLI, and Jamf School — is in the
**[project wiki](https://github.com/tonyyo11/jamf-reports-community/wiki)**.
