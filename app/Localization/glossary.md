# Translation glossary

Used for every string in `Localizable.xcstrings`, so a term reads the same on every screen. Formal
register: French `vous`, Spanish `usted`, German `Sie`. Spanish is neutral European (`ordenador`).

**Never translate:** Jamf Pro, Jamf Protect, Jamf School, Jamf Account, Jamf Cloud, Jamf Security
Cloud, Jamf Reports, jamf-cli, jamf-reports, Config Doctor, FileVault, Gatekeeper, SIP, XProtect,
Secure Boot, mSCP, STIG, SOFA, DDM, MDM, APNs, UDID, EA, CSV, HTML, PDF, XLSX, API, OAuth2, HTTP,
Homebrew, GitHub, Finder, Console, Mac, macOS, iOS, iPadOS, iPad, iPhone, Apple silicon, T2,
config.yaml and every config key, command, flag, path and file name, anything in backticks.
