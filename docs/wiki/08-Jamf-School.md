# Jamf School

Use this path when you manage an iOS/iPadOS fleet through Jamf School and want workbook
reporting from either a Jamf School device CSV export or live `jamf-cli school` data.

It produces a standalone Jamf School workbook with sheets for device inventory, OS
versions, device status, stale devices, overview, device groups, users, classes, apps,
profiles, and locations, all generated by the native Swift engine.

## Prerequisites

A CSV export needs no credentials. For live data, install `jamf-cli` (v1.18.0+, see
[Installation](01-Installation)). Connect a Jamf School profile from the app — during
onboarding choose the Jamf School product, or add it later from the **Sources** screen.
The app runs `jamf-cli school setup` for you and wires `school_cli.enabled`/`profile` into
`config.yaml`.

The relevant `config.yaml` sections (the app manages these):

```yaml
school_cli:
  enabled: false          # true when using live jamf-cli school commands
  data_dir: "school-cli-data"
  profile: "school"       # must match the jamf-cli school profile
  use_cached_data: true

school_columns:
  device_name: ""         # filled in by re-scaffolding against a CSV export
  serial_number: ""
  # ...
```

## CSV export format

Jamf School device exports use a semicolon (`;`) delimiter, not a comma. Export from
**Devices > Export** in the Jamf School web interface — the app reads the file directly,
no conversion needed.

## Using the app

1. Export a CSV from Jamf School (**Devices > Export**), or connect a live School profile.
2. In the **Config** screen, scaffold `school_columns` against the CSV export.
3. Review the detected `school_columns` — fuzzy matching is good but not perfect. Confirm
   `device_name` resolved to the display-name column, not a location or class name.
4. Generate the Jamf School workbook from the app. With a CSV it needs no credentials; with
   a connected School profile, collect first to add live-data sheets.

## What jamf-cli school commands are used

A School collect calls `school overview`, `school devices list`, `school device-groups
list`, `school users list`, `school groups list`, `school classes list`, `school apps
list`, `school profiles list`, and `school locations list`.
